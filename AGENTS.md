## Página branca — CAUSA RAIZ CORRIGIDA (09/08/2026)

- **Sintoma**: site inteiro branco (`ROOT` vazio) em TODOS os hosts, mesmo com servidor saudável e todos os módulos respondendo 200 via curl. O problema passou despercebido porque só se validava com HTTP (status 200), nunca com renderização real.
- **Causa**: o middleware de validação de URLs (SPA) de `server.ts` passava direto `/@vite`, `/node_modules`, `/assets` etc., mas **NÃO `/@react-refresh`** (módulo injetado pelo @vitejs/plugin-react no dev). O path (`/@react-refresh`, sem ponto) caía no check de página válida → `302 redirect "/"` → como o request era de script (`Accept: application/javascript`), o fallback SPA não servia HTML → **404 → o grafo de módulos do `main.tsx` abortava → app nunca montava**. Em produção (sem Vite) isso não ocorre.
- **Fix**: no bypass do middleware, `pathname.startsWith("/@vite")` → `pathname.startsWith("/@")` (cobre `/@vite`, `/@react-refresh`, `/@id`, `/@fs`...). Validado com navegador real.
- **Validação com navegador (nova regra)**: qualquer mudança que possa afetar render deve ser verificada com o **Playwright headless** (instalado como devDependency; browser em `%LOCALAPPDATA%\ms-playwright`, baixar com `npx playwright install chromium` se faltar). Teste rápido: abrir `http://localhost:3000/`, `http://adminfenix.localhost:3000/` e `http://suporte.localhost:3000/` e conferir `#root` com filhos + zero respostas 404 + zero pageerror (use o padrão do diagnóstico desta sessão: listeners de `response`/`pageerror`/`console`). `npm i`/`npm un` mudam package.json → Vite re-otimiza deps → `page reload` no log e janela de 404 transitória (aguardar estabilizar antes de testar).

## Backup & Restauração do Site (implementado 10/08/2026)

## Backup do Suporte (implementado 09/08/2026, validado end-to-end)
